# Godot FPS Prototype

Godot 4 First Person Shooter (FPS) Prototype

## 🛠️ Tools

Created with:

- [godot](https://godotengine.org) - the best game engine
- [krita](https://krita.org/) - the best image editor
- [blender](https://www.blender.org) - the best 3D modeling tool

## 📦 Assets

Assets from:

- [itio.io](https://itch.io) - various assets (fonts, audio, textures, etc.)
- [Sketchfab](http://sketchfab.com) - 3D models
- [Mixamo](http://mixamo.com) - characters, skeletons, and animations
- [ElevenLabs](http://elevenlabs.io) - audio effects and voices
